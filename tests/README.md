# Bootstrap seed test protocol

**Both test programs are host-only reference models. Neither compiles or executes
`src/scalar_codegen.atto`.**

## Rust — source arithmetic/diagnostic model

```sh
rustc --edition 2021 --test tests/scalar_seed_model.rs -o /tmp/atto-seed-model
/tmp/atto-seed-model --nocapture
```

Tests cover six known byte vectors, all 300 valid-shape ASCII expression
combinations, stable negative error codes and validation precedence, and
extreme signed-i64 invalid inputs. The checked implementation intentionally
avoids `then_some(ascii - 48)`: that eagerly evaluates the subtraction even
for invalid ASCII and can overflow for `i64::MIN` in debug builds.

## Node.js — actual WebAssembly execution from a host model

```sh
node --test tests/scalar_seed_wasm.test.mjs
```

This runner independently encodes each admitted three-byte fragment,
wraps it into a minimal valid no-import Wasm module that exports
`main(): i64`, validates it, and **executes it with Node's WebAssembly
engine**. All 300 digit/operator combinations are checked against an
independent arithmetic oracle. Invalid ASCII and tampered Wasm modules
must reject. The Wasm guest is generated by a JavaScript model, **not by
the `.atto` compiler source**.

## Evidence ladder

| Status | Required proof |
| --- | --- |
| Host-model | Commands above executed, test logs captured |
| Stage-0 Atto guest | Pinned real compiler compiles `src/scalar_codegen.atto`; executes genuine guest code on different inputs, with negative tests |
| Stage-1 | Atto-authored compiler can read external source and emit executable artifacts |
| Stage-2/3 | Atto compiler recompiles its full source, then repeats under pinned toolchains |

CI should print checked-out commit + root tree and tool versions. If
GitHub Actions fails before test steps execute, mark it **not executed**;
a workflow's `failure` status is not itself proof that code failed tests.

Full self-hosting criteria are in `docs/BOOTSTRAP_GATES.md`.
